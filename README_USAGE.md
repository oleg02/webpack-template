# 🎨 AI Фоторедактор - Інструкція користувача

## 🚀 Швидкий старт

### 1. Запуск проєкту

**Development режим:**
```bash
npm run dev
```
Відкриється браузер на `http://localhost:8081/`

**Production build:**
```bash
npm run build
```
Результат буде в папці `dist/` - відкрийте `dist/index.html` у браузері

### 2. Отримання API ключа Gemini

1. Перейдіть на https://ai.google.dev/ або https://makersuite.google.com/
2. Увійдіть через Google аккаунт
3. Натисніть "Get API Key" або "Create API Key"
4. Скопіюйте згенерований ключ

### 3. Використання програми

#### Крок 1: Введіть API ключ
При першому запуску ви побачите екран з полем для API ключа:
- Вставте скопійований ключ
- Натисніть "Зберегти"

#### Крок 2: Завантажте фото
- Натисніть на область "Натисніть для вибору файлу"
- Виберіть фото з вашого комп'ютера (PNG, JPG, WEBP)
- Побачите превʼю завантаженого зображення

#### Крок 3: Опишіть обробку
У текстовому полі напишіть, що ви хочете зробити з фото, наприклад:
- "Зроби це фото чорно-білим"
- "Додай теплі тони"
- "Зроби фон розмитим"
- "Покращ освітлення та контраст"
- "Зроби зображення в стилі ретро"

#### Крок 4: Обробіть зображення
- Натисніть "Обробити зображення"
- Зачекайте кілька секунд
- Побачите результат

#### Крок 5: Завантажте результат
- Якщо результат вас задовольняє, натисніть "Завантажити результат"
- Файл збережеться на ваш комп'ютер

## 🔧 Усунення проблем

### Проблема: "Сервер не запускається"
**Рішення:**
```bash
# Видаліть node_modules і встановіть заново
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### Проблема: "API повертає помилку"
**Можливі причини:**
1. Невірний API ключ - перевірте ключ
2. API ключ не активований - зачекайте 1-2 хвилини після створення
3. Перевищено ліміт запитів - зачекайте або створіть новий ключ

### Проблема: "Порт 8081 зайнятий"
**Рішення:**
Відредагуйте `build/webpack.dev.conf.js` і змініть порт:
```javascript
devServer: {
  port: 8082, // змініть на інший порт
  ...
}
```

### Проблема: "localhost не відкривається"
**Рішення:**
1. Використайте build версію:
   ```bash
   npm run build
   cd dist
   # Відкрийте index.html у браузері
   ```

2. Або запустіть простий HTTP сервер:
   ```bash
   npm run build
   cd dist
   python3 -m http.server 8080
   # Відкрийте http://localhost:8080
   ```

## 🔐 Безпека

- API ключ зберігається тільки в пам'яті браузера (Vuex state)
- Ключ НЕ зберігається в localStorage або cookies
- При перезавантаженні сторінки потрібно ввести ключ знову
- Ніколи не публікуйте ваш API ключ публічно

## 💡 Поради

1. **Будьте конкретними** в описі - чим детальніше, тим кращий результат
2. **Експериментуйте** з різними формулюваннями
3. **Використовуйте англійську** для кращих результатів (API краще розуміє англійську)
4. **Будьте терплячими** - обробка може зайняти 5-10 секунд

## 📞 Підтримка

Якщо виникли проблеми:
1. Перевірте консоль браузера (F12 > Console)
2. Перевірте статус API на https://status.cloud.google.com/
3. Перезапустіть dev сервер
